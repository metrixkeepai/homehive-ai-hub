5. OpenAI API connection plan — replace Lovable AI

Strong recommendation for production: stop calling ai.gateway.lovable.dev for Sera / capture / speech / live. Use OpenAI’s API directly with your own key and spend controls.

Why switch (cost + efficiency)

Lovable gateway adds an extra hop, opaque credits, and likely markup. Direct OpenAI gives invoiceable list pricing, org spend limits, standard SDKs, and simpler rate limiting. Combined with cheaper models + smaller record context (today Sera dumps ~150 items, live ~300 into gpt-6-astra), this is the largest operating-cost win available.
